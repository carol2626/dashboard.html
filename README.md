# Descomplica Vagas

Plataforma full stack para organizar oportunidades acadêmicas e profissionais, como estágios, bolsas, editais e processos seletivos.

## Objetivo

Ajudar estudantes a centralizar oportunidades, acompanhar prazos, etapas, documentos e status de candidatura em um único lugar.

## Problema que o projeto resolve

Muitos estudantes perdem oportunidades ou se desorganizam porque vagas, bolsas e processos seletivos ficam espalhados em diferentes sites, com prazos, exigências e etapas diferentes.

## Solução proposta

O sistema permitirá que o usuário:

- cadastre oportunidades manualmente ou por link
- acompanhe candidaturas
- visualize prazos importantes
- organize documentos e observações
- compare oportunidades
- acompanhe a preparação para entrevistas e testes
